# 11 Jenkins and CI-CD

Deliver a verified release through a repeatable pipeline.

Build your skills through practical lessons, hands-on labs, portfolio projects, and independent assessments. The curriculum connects technical understanding with verifiable results and troubleshooting practice.

## Your daily curriculum

| Day | Lesson | Observable outcome |
| --- | --- | --- |
| Day 01 | Pipeline concepts and Jenkins setup | Establish a bounded build environment and its trust boundaries. |
| Day 02 | Pipeline as code and agents | Run a defined build on an appropriate agent. |
| Day 03 | Tests, quality, and artifact publication | Connect build results to a versioned artifact. |
| Day 04 | Credentials and triggers | Use protected credentials and controlled build triggers. |
| Day 05 | Container build and publication | Produce and verify the intended image. |
| Day 06 | Deployment and environment checks | Deploy to the current lab environment and verify behavior. |
| Day 07 | Failure, approvals, and rollback | Recover from a controlled failed release. |
| Day 08 | CI/CD portfolio assessment | Explain and demonstrate the full delivery path and its limitations. |

Your portfolio connects working artifacts with evidence, explanations, and limitations. Document the decisions you make, the failures you investigate, and the checks that verify your results.
