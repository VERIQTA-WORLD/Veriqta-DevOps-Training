# VERIQTA DevOps Training

Learn DevOps by building, operating, investigating, and improving one evolving system.

You begin with Linux and networking. You then build automation, deploy to AWS, create a delivery pipeline, manage infrastructure as code, operate Kubernetes, and develop security and reliability practices.

[Start here](START-HERE.md) · [Curriculum](ROADMAP.md) · [Lesson index and status](PROGRESS.md) · [Project](project/README.md)

## How you learn

Each learning day gives you a concrete outcome, explanations, a guided lab, an independent task, and evidence to check. You build on earlier work and investigate failures rather than collecting disconnected tool demonstrations.

Plan around 60 minutes per session. Use a smaller 30-minute checkpoint when necessary. Installation and troubleshooting may take longer. Days are learning sessions, not calendar deadlines. If you miss a day, resume from your last verified checkpoint.

You can follow the published lessons independently. During guided instruction, run one step at a time and review the result before continuing.

## What you will build

Your fictional VERIQTA Learning Platform starts small and grows into a web frontend, Java API, and PostgreSQL database. You add operational automation, delivery, infrastructure, observability, and security as you learn. All example data is synthetic. See the [project progression](project/README.md).

You also produce portfolio evidence: reproducible deployments, troubleshooting notes, architecture decisions, runbooks, restore tests, and incident reports. A finished course supports your development; senior responsibility also requires real operational experience over time.

## Before you begin

- Use a personal Linux lab or another environment you are allowed to change.
- Begin with a regular user account and a terminal. Day 001 needs no cloud account or paid service.
- Read the [environment guide](docs/environment.md) before installing anything.
- Keep real credentials and private system details out of public submissions.
