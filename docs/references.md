# Official references

You do not need to read these manuals in full. Use the linked sections when you want to confirm behavior or investigate a difference on your system.

Day 001 reference review: 2 November 2026. Manuals can change. Record the actual installed tools when reporting a compatibility issue.

| Subject | Official reference | Why it matters |
| --- | --- | --- |
| Bash commands and quoting | [GNU Bash manual](https://www.gnu.org/software/bash/manual/bash.html) | The shell interprets commands, quotes, variables, and redirection. |
| uname | [GNU uname manual](https://www.gnu.org/software/coreutils/manual/html_node/uname-invocation.html) | Kernel information and machine architecture. |
| id | [GNU id manual](https://www.gnu.org/software/coreutils/manual/html_node/id-invocation.html) | Account names and numeric identity. |
| mkdir | [GNU mkdir manual](https://www.gnu.org/software/coreutils/manual/html_node/mkdir-invocation.html) | Creating the private practice workspace. |
| Files, paths, dates, and disk reports | [GNU Coreutils manual](https://www.gnu.org/software/coreutils/manual/coreutils.html) | Confirm the behavior of the individual utilities used in the lab. |
| Distribution identity | [os-release specification](https://www.freedesktop.org/software/systemd/man/latest/os-release.html) | Distinguish Linux kernel identity from distribution information. |
| vi editing | [Vim tutorial](https://vimhelp.org/usr_02.txt.html) | Modal editing when vi is provided by Vim; other vi implementations may differ. |
| Future cloud cost controls | [AWS Budgets guide](https://docs.aws.amazon.com/cost-management/latest/userguide/budgets-managing-costs.html) | Billing information and notifications can arrive after resource use. |
| Future container orchestration | [Kubernetes container runtimes](https://kubernetes.io/docs/setup/production-environment/container-runtimes/) | Separate Docker image-building workflows from Kubernetes runtime requirements. |
