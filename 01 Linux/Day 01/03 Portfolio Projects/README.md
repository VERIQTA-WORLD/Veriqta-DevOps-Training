# Day 01 portfolio projects

You will complete two small foundation projects. They are useful records of engineering practice, not claims that you have deployed a production application.

Complete the guided lab first. Save your project output in your own private Day 01 workspace. Each project below explains its deliverable, verification, and limits.

1. [Project 01, System Baseline](01%20System%20Baseline.md).
2. [Project 02, Environment Handover](02%20Environment%20Handover.md).

![Diagram connecting a verified baseline to an explained environment handover.](../07%20Images/portfolio-projects.svg)

Text equivalent: Project 01 captures actual environment observations. Project 02 explains how someone can locate and interpret that record. Both need verification and clearly stated limits.

## How this connects to the course project

You will later operate a fictional learning-platform application. Today's baseline is the first record of the environment beneath it. Keep the same private workspace as the application evolves. Each future day will state the previous artifact it builds on and the new result you must verify.

All project teaching material stays inside its tool and day. There is no separate root project or portfolio folder to navigate.
