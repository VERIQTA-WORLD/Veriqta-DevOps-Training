# Day 01 portfolio projects

Build two connected Linux projects and publish your own results in a GitHub portfolio. You will work through each project from the first directory command to the final repository check.

| Project | What you build | What you demonstrate |
| --- | --- | --- |
| [01 System Baseline](01%20System%20Baseline.md) | A verified Linux environment report, a reproducible project README, and a verification record. | Environment inspection, evidence-based reporting, file verification, and clear technical documentation. |
| [02 Environment Handover](02%20Environment%20Handover.md) | A working handover guide, an operator walkthrough, and a tested recovery scenario. | Operational communication, portable instructions, path troubleshooting, and continuity. |

Complete Project 01 first. Project 02 uses its saved baseline and extends the same portfolio repository. These are complete beginner projects with modest technical scope. Your claims should match the work you actually perform.

## Before you begin

Complete the [Day 01 lab](../02%20Follow%20Along%20Lab/README.md). You need your Linux terminal, a regular user account, vi, and a GitHub account. The publication steps use GitHub in a web browser, so you do not need Git commands yet. Create your own repository, rather than editing the shared training repository.

Allow approximately 60 to 90 minutes per project, including writing, verification, and publication. You can divide a project into several sessions. Resume from its last verified step.

## Your finished portfolio

Use one personal repository named `linux-foundations-portfolio` with the following files:

| Repository path | Created in | Purpose |
| --- | --- | --- |
| README.md | Project 01, expanded in Project 02 | Introduces your work and links to the projects. |
| system-baseline/README.md | Project 01 | Explains and reproduces your environment inspection. |
| system-baseline/baseline.md | Project 01 | Records reviewed observations from your actual environment. |
| system-baseline/verification.md | Project 01 | Records checks you actually performed and their results. |
| environment-handover/README.md | Project 02 | Introduces and verifies your handover project. |
| environment-handover/handover.md | Project 02 | Gives an operator an actionable procedure. |
| environment-handover/verification.md | Project 02 | Records the walkthrough, a controlled error, and recovery. |

The folder names and relative links matter. Both tutorials explain how to create and check them. These files live in your portfolio repository; the tutorials remain here in the course.
