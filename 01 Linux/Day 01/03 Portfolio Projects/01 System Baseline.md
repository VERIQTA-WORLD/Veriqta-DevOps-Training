# Project 01, Your Linux System Baseline

## The problem

You need a reliable starting record before installing the future application. A list of copied example values would mislead later troubleshooting.

## Your deliverable

Use the `baseline.md` you created in the lab. It must record your actual capture time, kernel, distribution, architecture, current identity, Bash version, workspace, and available space for that workspace. Add one verified observation and one limit of the evidence.

Add a section named `Before installing software` with two checks you would repeat: one for download compatibility and one for the working directory. Name the command and the specific result you would inspect.

## Verify the project

Leave the directory, return, and read the saved file. Compare its observations with your current command results. If a value changed, explain the change and its observation time rather than altering history silently.

You pass when the file is real, readable, based on actual output, and clear about its scope. Do not claim that it proves application health or complete security.

## Portfolio evidence

Keep the original privately. For a public demonstration, use a reviewed redacted copy and describe the task, checks, result, and limitations. Never present invented success output as observed evidence.
