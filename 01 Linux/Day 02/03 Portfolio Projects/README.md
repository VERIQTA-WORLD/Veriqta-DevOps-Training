# Day 02 portfolio projects

Build and publish two connected projects. Both are complete follow-along tutorials, including local file creation, expected results, verification, troubleshooting, and GitHub publication.

| Project | Your result |
| --- | --- |
| [01 Learning Platform Workspace](01%20Learning%20Platform%20Workspace.md) | An organized application workspace with synthetic configuration, a hidden marker, a reproducible README, and an inventory record. |
| [02 Configuration Change and Recovery](02%20Configuration%20Change%20and%20Recovery.md) | A documented change, preserved before-change copy, verified restoration, and recovery instructions. |

Project 02 builds on Project 01. Keep your earlier Day 01 portfolio and use the same personal repository, linux-foundations-portfolio. Your local work stays under the Day 02 portfolio path. The course repository contains the tutorials, not your personal results.

Allow 60 to 90 minutes per project, including documentation and publication. You can pause at a verified checkpoint. Use real observations and synthetic application data.
