# 03 Git and GitHub

Deliver and recover a reviewed application change.

Build your skills through practical lessons, hands-on labs, portfolio projects, and independent assessments. The curriculum connects technical understanding with verifiable results and troubleshooting practice.

## Your daily curriculum

| Day | Lesson | Observable outcome |
| --- | --- | --- |
| Day 01 | Repository and history | Create meaningful commits and inspect the history. |
| Day 02 | Branches and changes | Develop an isolated change and compare it with the starting state. |
| Day 03 | Remotes and authentication | Push to your authorized repository without exposing credentials. |
| Day 04 | Pull requests and review | Propose and explain a focused change. |
| Day 05 | Merge conflicts | Resolve a deliberate conflict and verify the result. |
| Day 06 | Recovery, tags, and releases | Recover a bad change and identify a reproducible release. |
| Day 07 | Collaboration assessment | Deliver a reviewed release with clear history and recovery evidence. |

Your portfolio connects working artifacts with evidence, explanations, and limitations. Document the decisions you make, the failures you investigate, and the checks that verify your results.
