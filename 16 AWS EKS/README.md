# 16 AWS EKS

Operate the application on a managed Kubernetes platform.

Build your skills through practical lessons, hands-on labs, portfolio projects, and independent assessments. The curriculum connects technical understanding with verifiable results and troubleshooting practice.

## Your daily curriculum

| Day | Lesson | Observable outcome |
| --- | --- | --- |
| Day 01 | Responsibilities and cluster plan | Choose bounded compute, identity, networking, and cost assumptions. |
| Day 02 | Cluster access and compute | Create the authorized lab cluster and verify access. |
| Day 03 | Workload identity | Grant a workload narrowly scoped cloud permissions. |
| Day 04 | Networking and traffic | Verify the application request path and cloud load balancing. |
| Day 05 | Persistent storage | Provision and test the intended storage behavior. |
| Day 06 | Operations, upgrades, and observability | Investigate a bounded issue and review upgrade responsibilities. |
| Day 07 | EKS portfolio and teardown | Demonstrate deployment and recovery, then remove billable resources. |

Your portfolio connects working artifacts with evidence, explanations, and limitations. Document the decisions you make, the failures you investigate, and the checks that verify your results.
