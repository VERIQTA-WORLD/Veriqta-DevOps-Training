# 13 Ansible

Configure the lab hosts repeatably and safely.

Open the days below in order. Each day will contain its own notes, follow-along lab, portfolio projects, knowledge checks, assessment, troubleshooting, images, and evidence guidance. Day numbers restart within this tool.

## Your daily curriculum

| Day | Lesson | Observable outcome |
| --- | --- | --- |
| Day 01, planned | Inventory and connectivity | Target only authorized lab hosts. |
| Day 02, planned | Modules, playbooks, and variables | Apply and explain a small desired configuration. |
| Day 03, planned | Templates and handlers | Update service configuration and restart only when needed. |
| Day 04, planned | Roles and secret boundaries | Organize configuration while protecting sensitive values. |
| Day 05, planned | Idempotence and controlled rollout | Verify repeat execution and diagnose a failed host. |
| Day 06, planned | Configuration portfolio assessment | Recreate service configuration with a documented recovery path. |


Planned means the complete lesson has not been published. Only available lessons have links. Do not treat a curriculum outline as a completed class.

Your practical portfolio grows inside these lessons. Each published day's portfolio projects explain what to build, what to verify, what to retain, and what the result demonstrates.
