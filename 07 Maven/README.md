# 07 Maven

Produce a tested, versioned Java application artifact.

Build your skills through practical lessons, hands-on labs, portfolio projects, and independent assessments. The curriculum connects technical understanding with verifiable results and troubleshooting practice.

## Your daily curriculum

| Day | Lesson | Observable outcome |
| --- | --- | --- |
| Day 01 | Java essentials and project structure | Run the small API project and explain its files. |
| Day 02 | POM and dependencies | Declare and inspect required dependencies. |
| Day 03 | Build lifecycle and tests | Build and investigate a failing test. |
| Day 04 | Versions and reproducibility | Identify the source and dependencies behind an artifact. |
| Day 05 | Maven portfolio assessment | Deliver a tested artifact and diagnose a broken build. |

Your portfolio connects working artifacts with evidence, explanations, and limitations. Document the decisions you make, the failures you investigate, and the checks that verify your results.
