# Linux, Week 01

You begin by identifying your environment and creating a safe workspace. You then use files, permissions, logs, and processes to understand the foundation beneath a service.

This week groups up to five learning sessions. Complete them at a sustainable pace. Return to the [canonical lesson index](../../../PROGRESS.md) for published days, planned days, and verification status.

Begin with [Day 001, Your Linux Environment and First System Baseline](day-001-environment-and-baseline/README.md).

The planned end-of-week checkpoint combines file organization, permission reasoning, log investigation, and process inspection. It will be supplied with the relevant lessons, not presented as an assessment you have already passed.
