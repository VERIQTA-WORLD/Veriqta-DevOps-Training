# Day 001 project connection

Your future application will run on infrastructure. Today you create the first operational record for that infrastructure: an environment baseline.

## Contribution to the project

Your private `$HOME/veriqta-devops-labs/day-001/baseline.md` captures the starting environment. It will help you choose compatible software and explain differences between your machine and a tutorial.

Keep it outside the public repository because it can contain identity and system details. A later lesson will show you how to create a safe public project record with synthetic identifiers. The public [project directory](../../../../project/README.md) remains the canonical location for shared application and platform code when it is introduced.

## Small independent variation

Reopen your baseline in vi and add a short section titled `Before installing software`.

Write two concrete checks based on today's observations:

1. One check that would help you select a compatible download.
2. One check that would help you avoid changing files in the wrong directory.

State the command you would use and what result you would inspect. Save and read the file again. You can consult the notes, but your checks must match your actual environment.

## What counts as success

You have a real saved file, can locate it from another directory, and can explain why its observations matter. You have not deployed an application yet and should not describe this milestone as a production deployment.
