# Module 01, Linux

Before you deploy an application, you need to know where it runs, which account controls it, where its files live, and how to investigate what the system is doing.

Linux provides the foundation for much of the infrastructure you will use later. You will learn it through observable work rather than a list of commands to memorize.

## Prerequisites

You need a terminal and an authorized Linux lab environment. Start with the [environment guide](../../docs/environment.md). No prior Linux knowledge is assumed.

## Outcomes

By the end of this module, you should be able to:

- Navigate files and explain paths, ownership, and permissions.
- Read and filter logs to answer a specific question.
- Inspect users, processes, services, and resource use.
- Understand packages, SSH, disks, mounts, and scheduled work.
- Run a small service and verify its behavior.
- Investigate a controlled failure, recover safely, and document the evidence.

These outcomes span more than the first five sessions. A week is an organizational unit, not a claim that you can master Linux in five days.

## How you demonstrate progress

You will combine guided practice with independent tasks. The eventual module assessment will ask you to investigate a service problem using logs, process information, permissions, and resource evidence. You will explain why you chose each action and verify the result.
