# Start here

Your first goal is small and useful: identify your Linux environment and create a record you can refer to before changing it.

## 1. Prepare your environment

Read the [environment guide](docs/environment.md). You need a Linux terminal, Bash, common Linux utilities, and vi. You do not need Docker, Kubernetes, an AWS account, or Git installed for Day 001. You can read the lesson directly on GitHub.

If you have no Linux environment yet, stop before running the lesson and arrange a disposable Linux machine or VM. Tell your instructor your operating system and available resources so setup can be tailored. Do not copy Linux commands into PowerShell or macOS Terminal and assume the results mean the same thing.

## 2. Separate the course from your work

The GitHub repository contains shared teaching material. Your local practice lives under `$HOME/veriqta-devops-labs/`, outside any repository checkout. `$HOME` is your home directory; Bash substitutes its actual path. Do not reassign that variable.

Keep raw screenshots and system details private. You will learn Git in depth in Module 03. Before then, save your files locally and back them up using an approved private location. You do not need to publish personal output to complete a lesson.

## 3. Follow this session pattern

1. Recall the previous result and read today's outcome.
2. Read the explanation and predict what the next command should show.
3. Run the guided lab, one command at a time.
4. Check actual results against the stated criteria.
5. Complete the independent task and record the next checkpoint.

You may look up syntax. Your goal is to explain and verify your work, not memorize every option.

## 4. Begin Day 001

Open [Day 001](modules/01-linux/week-01/day-001-environment-and-baseline/README.md), then follow its lesson links in order. During live instruction, begin with the environment check and wait for feedback before dependent steps.

Do not skip a failed command and mark the task complete. Use the troubleshooting guide, preserve the exact error, and ask for help with a redacted transcript if necessary.
