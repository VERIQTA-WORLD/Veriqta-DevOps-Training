# 12 Terraform

Review, create, change, and recover infrastructure through code.

Open the days below in order. Each day will contain its own notes, follow-along lab, portfolio projects, knowledge checks, assessment, troubleshooting, images, and evidence guidance. Day numbers restart within this tool.

## Your daily curriculum

| Day | Lesson | Observable outcome |
| --- | --- | --- |
| Day 01, planned | Providers and first resources | Create a small bounded resource after reviewing its plan. |
| Day 02, planned | Variables, outputs, and dependencies | Make the lab configuration understandable and reusable. |
| Day 03, planned | State and sensitive data | Inspect state responsibilities without publishing sensitive values. |
| Day 04, planned | Remote backend and locking | Configure a suitable backend and verify concurrency protection. |
| Day 05, planned | Modules and environments | Reuse a small module with explicit environment boundaries. |
| Day 06, planned | Plans, changes, and drift | Investigate a deliberate difference between code and infrastructure. |
| Day 07, planned | Import and recovery | Bring a bounded resource under management and explain the risks. |
| Day 08, planned | Infrastructure portfolio assessment | Rebuild the lab and verify teardown and remaining costs. |


Planned means the complete lesson has not been published. Only available lessons have links. Do not treat a curriculum outline as a completed class.

Your practical portfolio grows inside these lessons. Each published day's portfolio projects explain what to build, what to verify, what to retain, and what the result demonstrates.
